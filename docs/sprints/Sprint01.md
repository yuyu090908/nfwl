## 実装した機能

- UE5 C++ プロジェクト雛形（NFWL モジュール、Enhanced Input、Git LFS 設定）
- 42m×25m ピッチ、ライン、センターサークル、ペナルティエリア（半径6m半円）、幅3m×高さ2mのゴールとネットを実行時に生成
- ボール：4号相当（半径11cm・0.40kg）、反発・摩擦・減衰、CCD（高速シュートのすり抜け防止）、レプリケーション有効
- 選手：能力値（Speed / Acceleration / Agility 等）から最高速度6.0〜7.4m/s、加速1.6〜1.0秒、旋回速度を算出
- ドリブル：近くの遅いボールを自動トラップ、足元0.7m（ダッシュ時1.9m）前にボールを運ぶ
- パス・ロングパス・シュート：長押しでパワー（1.0秒で最大、0.15秒未満はタップ）、能力値による狙いのブレ、強すぎるシュートは浮く、軽いシュートアシスト、150msの入力バッファ
- ゴール判定・アウト判定（ボール全体がラインを越えたか）をGameModeで判定し、得点後はキックオフ位置へリセット
- 斜め俯瞰のサイドビューカメラ、スコア・パワーゲージのHUD
- 自動テスト3件（能力値換算、長押し判定、ゴールライン判定）
