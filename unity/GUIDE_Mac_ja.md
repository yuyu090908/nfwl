# Mac で NFWL（Unity版）を開いて遊ぶまでの手順

Unity がはじめての方向けに、1つずつ順番に書いています。全部で 30〜60分ほどです（ほとんどはダウンロードの待ち時間です）。

---

## 0. 準備するもの

- Mac（Apple シリコン M1〜M4 でも Intel でも可）
- 空き容量 **20GB 以上**（Unity 本体が大きいため）
- インターネット接続
- メールアドレス（Unity のアカウント作成に使います。無料です）

---

## 1. Unity Hub をインストールする

Unity Hub は「Unity 本体やプロジェクトを管理するアプリ」です。まずこれを入れます。

1. Safari などで **https://unity.com/download** を開きます。
2. 「**Mac 用ダウンロード**」（Download for Mac）を押します。`UnityHubSetup.dmg` がダウンロードされます。
3. ダウンロードした `UnityHubSetup.dmg` をダブルクリックします。
4. 利用規約が出たら「**同意する**」（Agree）を押します。
5. 出てきたウィンドウで **Unity Hub のアイコンを「Applications」フォルダへドラッグ**します。
6. Launchpad または「アプリケーション」フォルダから **Unity Hub** を開きます。
   - 「インターネットからダウンロードされたアプリです。開いてもよろしいですか？」と出たら「**開く**」を押します。

## 2. Unity にサインインする

1. Unity Hub が開くと「**Sign in**」（サインイン）を求められます。
2. アカウントがない場合は「**Create account**」から、メールアドレスとパスワードで作成します（Google / Apple アカウントでも可）。
3. サインインすると、無料の「**Unity Personal**」ライセンスが自動で付きます。
   - もし「ライセンスがありません」と出たら、Unity Hub 左下の歯車（設定）→「**Licenses**」→「**Add**」→「**Get a free personal license**」を選びます。

## 3. Unity 本体（エディター）をインストールする

1. Unity Hub の左側メニューで「**Installs**」（インストール）を選びます。
2. 右上の「**Install Editor**」（エディターをインストール）を押します。
3. 「Official releases」タブの一番上にある **Unity 6.3 (LTS)** の「**Install**」を押します。
   - LTS は「長期サポート版」で、いちばん安定している版です。表示が 6.3 でなくても、**「LTS」と書かれた Unity 6 の版**ならどれでも大丈夫です。
4. 追加モジュールを選ぶ画面が出ます。**何もチェックを増やさずに**「**Install**」（または Continue）を押して大丈夫です。
   - 「Visual Studio Code」等の質問が出たら、スキップしてかまいません。
5. ダウンロードとインストールが終わるまで待ちます（10〜30分ほど）。

## 4. NFWL のプロジェクトを Mac にダウンロードする

1. Safari で次のページを開きます（GitHub にログインした状態で開いてください）。
   **https://github.com/yuyu090908/nfwl**
2. 画面上の緑色の「**Code**」ボタン →「**Download ZIP**」を押します。
   - プルリクエストがまだマージ（取り込み）されていない場合は、先にブランチを切り替えます：画面左上の「main」と書かれたボタンを押し、`claude/project-thread-kdvpa7` を選んでから「Code」→「Download ZIP」を押してください。
3. 「ダウンロード」フォルダに ZIP ができます。ダブルクリックすると展開されて `nfwl-…` というフォルダができます。
4. そのフォルダを「書類」（Documents）などわかりやすい場所へ移動しておきます。
   - Unity のプロジェクトは、その中の **`unity` → `NFWL`** フォルダです。

## 5. Unity Hub でプロジェクトを開く

1. Unity Hub の左側メニューで「**Projects**」（プロジェクト）を選びます。
2. 右上の「**Add**」（追加）の横の ▼ を押し、「**Add project from disk**」（ディスクから追加）を選びます。
3. さきほどのフォルダの中の **`unity/NFWL`** フォルダを選んで「**Open**」を押します。
   - `NFWL` フォルダの中に `Assets` と `ProjectSettings` が見える場所が正解です。
4. 一覧に「NFWL」が追加されます。
   - エディターのバージョン欄に ⚠ マークや「not installed（インストールされていません）」と出ても大丈夫です。その欄を押して、**手順3で入れた Unity 6 のバージョンを選んで**ください。
5. 「NFWL」をクリックして開きます。
   - 「Change Editor version?」「Opening Project in Non-Matching Editor Installation」などのお知らせが出たら「**Continue**」（続行）や「**Change Version**」を押します。
   - 初回は準備に **数分** かかります。

## 6. 遊ぶ

1. Unity の画面が開くと、自動で「Main」シーン（ゲームの舞台）が作られて開きます。
   - 画面下の「Console」に「NFWL: Assets/Scenes/Main.unity を作成しました」と出ていれば OK です。
   - 開かれていないときは、画面上のメニュー「**NFWL**」→「**Open Main Scene**」を選びます。
2. 画面の上中央にある **▶（再生ボタン）** を押します。
3. 「Game」の画面を一度クリックしてから、キーボードで操作します。

| 操作 | キー |
| --- | --- |
| 移動・ドリブル | W A S D（または矢印キー） |
| ダッシュ | Shift |
| ショートパス | J（向いている方向の味方へ。長押しで強く） |
| スルーパス | Alt（Option）+ J |
| 守備時のタックル | 相手ボールのとき、相手の近く（2.6m以内）で J |
| ロングパス | L（長押しで強く・高く） |
| 浮き球のスルーパス | Alt（Option）+ L |
| シュート | K（長押しでチャージ、強すぎると浮く） |
| パワーシュート／コントロールシュート／グラウンダー | Shift + K ／ Alt（Option）+ K ／ Ctrl + K |
| 操作する選手を切り替える | Q（ボールに一番近い味方へ） |
| カメラの寄り・引き | Z |
| キックオフに戻す／試合終了後にもう一度 | R |
| リプレイを飛ばす | Space（J / K / L でも可） |
| 音のオン／オフ | M |
| AIの役割表示（確認用） | F1 |
| 性能表示（FPS など、確認用） | F2 |
| 自動試合（CPU対CPUで見る） | F4 |

- 足元に黄色い円が出ている黒いユニフォームの選手があなたです。ボールに近づくと自動でトラップし、左下の選手カードに **BALL** と出ます。
- 画面 **右側のゴール** にシュートを入れると「GOAL!」と出て、上のスコアが増えます。
- もう一度 ▶ を押すと停止します。

---

## うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| 「Enter Safe Mode?」と出た | プログラムにエラーがある合図です。「**Ignore**」を押して開き、画面下「Console」に出た **赤い文字** をコピーして送ってください。すぐ直します。 |
| ▶ を押してもキーで動かない | 「Game」画面を一度クリックしてください。画面に「Keyboard input is off」と出ていたら、メニュー「Edit」→「Project Settings」→「Player」→「Other Settings」の「**Active Input Handling**」を「**Both**」にして Unity を再起動します。 |
| 画面に何も出ない | 「NFWL」→「Open Main Scene」を選んでから ▶ を押してください。 |
| Unity Hub でプロジェクトを追加できない | 選んだフォルダが `unity/NFWL` か確認してください（`Assets` が入っているフォルダ）。 |

困ったら、画面のスクリーンショット（⌘ + Shift + 4）を送ってもらえれば、次の手を案内します。
