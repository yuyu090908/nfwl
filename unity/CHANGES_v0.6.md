# NFWL Unity v0.6「REAL FOOTBALL EVOLUTION」作業記録

v0.5 Crystalia（ブランチ `claude/project-thread-kdvpa7`）から段階的に進めています。

## 確認のしかた（Mac）

1. ターミナルで：
   ```
   cd （nfwl をクローンしたフォルダ）
   git fetch origin
   git checkout claude/project-thread-kkc9n8
   git pull
   ```
2. Unity を一度閉じて、Unity Hub から同じ `nfwl/unity/NFWL` を開き直す
3. メニュー **NFWL → Open Main Scene** → ▶

## 調整ファイル

メニュー **NFWL → Create Tuning File** で `Assets/Resources/NFWLTuning.asset` ができます。
選択すると Inspector に移動・旋回などの数値が並び、変更は試合に反映されます（Play中の変更もEditorでは約1秒で反映）。
ファイルを作らなくても、コード内の初期値（v0.5 と同じ速度基準）で動きます。

## STEP 2：選手移動・加減速・旋回・重心（実装済み・実機未確認）

- 新規：`Core/NFWLTuning.cs`（調整値）、`Player/PlayerLocomotion.cs`（移動）
- 変更：`PlayerController.cs`（移動処理を PlayerLocomotion に置き換え）、`PlayerModel.cs`（傾き・横移動・後退・踏ん張りの表示）、`MatchManager.cs`（バージョン表示と移動状態の表示）、`Editor/NFWLProjectSetup.cs`（調整ファイル作成メニュー）
- 走る向き（速度）と体の向きを別々に管理。ダッシュ中に逆方向を押すと、その場で反転せず「踏ん張って減速 → 軸足で回る → 押し出して再加速」（約0.5秒）。
- カーブは Agility による横方向のグリップで曲がれる量が決まり、急な角度ほど減速。
- 前傾：速度と加速で前に傾き、急停止では上体が慣性で前に出てから戻る。カーブでは内側に傾く。
- 速いダッシュからの急旋回でバランスを崩し、回復中（Recovery）は少し遅く、腕を広げる。
- 守備：ボールを持った相手の4m以内で Shift を押していないと、相手を向いたまま横移動・後退（ジョッキー）。Shift で通常の走りに戻る。
- Speed / Acceleration / Agility が最高速・加速時間・旋回とバランス回復に効く（v0.5 の数値を初期値として維持）。

**見るところ**：画面右上のバージョンの下に、操作中の選手の状態（`Sprint` `SharpTurn` `PivotTurn` `Backpedal` `Jockey` など）・速度・傾き・バランスが出ます。Shift+D で走ってから A を押すと `SharpTurn → PivotTurn → Accelerate` と変わり、体がくるっと反転しないことを確認してください。

## STEP 3：足の接地・IK・自然な走行（実装済み・実機未確認）

- 新規：`Animation/LegIK.cs`（2ボーンIK：股関節→膝→足首）、`Animation/GaitController.cs`（足の接地・踏み出し）
- 変更：`PlayerModel.cs`（足首の関節を追加し、脚をIKで動かす。アニメは LateUpdate で移動後に計算）
- 接地中の足は地面に固定（Foot Locking）。次の着地点は体の速度から予測し、歩幅＝速度÷ピッチで自動的に合う（Stride Synchronization）。
- ピッチ（1秒あたりの歩数）は速度で上がり、接地時間は「脚が届く範囲（約0.8m）を体が通過する時間」に合わせるので、足が届かずに滑ることを防ぐ。
- 骨盤の高さ調整：接地足が届かないときだけ腰を必要な分だけ下げる。走行時は1歩ごとに上下動。
- 地面の高さと傾きをレイキャストで取り、足の高さと足裏の角度を合わせる（Slope Adaptation。今のピッチは平らなので見た目の変化はほぼなし）。
- 立ち止まって向きを変えると、足踏みで向き直る（体が回るのに足が滑らない）。ピボット中は軸足のつま先で回る。
- 横移動・ジョッキーは足幅を広げ、左右の足が交差しないよう着地点を補正。
- 走りの腕振りは実際の脚の位置から計算（左脚が前なら左腕は後ろ）、骨盤と肩が逆向きにひねられる。
- キックとGKのダイブ・ゴールのジャンプ中は、その脚のIKを切って従来の動き（STEP 5 で作り直し）。

**見るところ**：選手の靴が芝の上で滑らず、踏んでから離れること。走り出し・急停止・その場での向き直りで足踏みすること。右上表示の末尾 `foot` は、接地足が脚の長さで届かなかった距離（cm）で、ほぼ 0.0 なら滑っていません。

## STEP 4：ドリブルとボールタッチ（実装済み・実機未確認）

- 新規：`Player/DribbleController.cs`（タッチの計画と実行）
- 変更：`Ball.cs`（転がり抵抗・空気抵抗を明示的に計算し、同じ式でボールの位置を予測できるように。重さ0.40kg・半径0.11mは維持）、`PlayerController.cs`（毎フレームの引き寄せを廃止してタッチ方式に）、`PlayerModel.cs`（足をボールへ振る「フットアクション」）、`NFWLRules.cs`（利き足 PreferredFoot・逆足 WeakFootRating を追加。既存データは右足・3）、`MatchManager.cs`（利き足の割り当て、選手カードに L/R と WF 表示）
- ボールは常に独立した物理オブジェクト。保持（Owner）は「誰がドリブル中か」の管理だけで、位置は固定しない。
- タッチの流れ：タッチが必要になる → 足を選ぶ → 足がボールの来る位置へ振られる → **足が触れた瞬間に**ボールへ新しい速度を与える。次に追いつく地点を予測してタッチの強さを決める。
- タッチの種類：通常／ダッシュ（大きく前へ）／クローズコントロール（相手が近い・遅いとき細かく）／方向転換タッチ（インサイド・アウトサイド）／ファーストタッチ（受けたとき）／足裏（大きな切り返し）／ストップ（入力なしで止める）／シールド（相手を背にしてボールを隠す）。
- 足の選び方：ボールが左なら左足、右なら右足、中央なら走りの周期で空いている足・交互。体の前を横切る足は使わない。
- BallControl：タッチの間隔（細かさ）と精度、ファーストタッチの柔らかさ。Agility：方向転換タッチをどれだけ早く出せるか。逆足は精度が落ちる（WeakFootRating で軽減）。
- 補助は「進行方向に沿ってボールがぶれないようにする弱い補正」だけで、足元への引き寄せはしない。
- シュート・パスのキーを押したときボールが足元にない場合は、最大0.8秒、ボールに追いついてから蹴る（足が届く前にボールが飛ぶことはない）。キックの足の動き自体は STEP 5 で作り直し。

**見るところ**：ドリブル中、ボールが足元に吸い付かず、足が当たるたびに転がり出ること。右上に `TOUCH Normal / Sprint / CloseControl / Inside / Outside / Sole / Stop / SHIELD` と最後のタッチの種類が出ます。Shift でダッシュするとボールが前に大きく出て、急に止まると足裏で止めます。

## STEP 5：キックモーションとボール接触の同期（実装済み・実機未確認）

- 新規：`Player/KickController.cs`（キックの7段階のタイムライン）
- 変更：`PlayerController.cs`（キーを押した瞬間ではなく、足が当たった物理ステップでボールを蹴る）、`PlayerModel.cs`（軸足の踏み込み、蹴り足のバックスイング→振り下ろし→フォロースルー、骨盤の回転・上体の傾き・腕のバランス）
- キックは「準備 → 踏み込み → 軸足接地 → バックスイング → インパクト → フォロースルー → 回復」の順に進む。強いキックほどバックスイングが大きく長い。向きを大きく変える必要があるときは準備が長くなる。
- 軸足はボールの横（蹴り足の反対側）に置かれ、つま先が狙う方向を向く。
- 蹴り足はボールが「インパクトの瞬間にいる位置」を予測して振られ、ボールは**その物理ステップで**初めて飛び出す（キー入力直後にボールだけ飛ぶことはなくなった）。足が届いていなければ空振り。
- 足の選び方：利き足が基本。ボールが反対側にはっきりあるときは逆足（精度が WeakFootRating に応じて下がる）。
- フォーム：ショートパスはインサイド・小さい振り、ロングパスは上体を後ろに傾けて大きく振り上げ、シュートは甲（足首固定）でボールにかぶさる。
- キック中は体が狙う方向へ（通常の旋回速度で）向き直る。以前のような一瞬での向きの切り替えは廃止。走る速さはキック中に落ち、回復で元に戻る。
- GKは手に持ったボールを落として蹴る（ドロップキック）。
- パス・シュートの球速と角度の計算は v0.5 のまま（STEP 6 で種類を増やして作り直し）。

**見るところ**：K/J/L を押したあと、足を振り上げて当たった瞬間にボールが飛ぶこと。右上に `KICK Approach / PlantFoot / Backswing / FollowThrough / Recovery` と段階が出ます。長押しの強いシュートほど振りかぶりが大きくなります。

## STEP 6：パス・シュート・ボール回転（実装済み・実機未確認）

- 新規：`Ball/BallSolver.cs`（ボールの物理モデルを使って、届く球速・角度・カーブの狙いを逆算）、`Player/KickPlanner.cs`（パス・シュートの種類ごとの球速と回転）、`Ball/BallContacts.cs`（足・胴・頭へのボールの当たり）
- 変更：`Ball.cs`（回転とマグヌス効果、バウンド時の回転、ポスト・クロスバーの反発、ネットで勢いを吸収、当たった瞬間のボールのつぶれ表示、空気抵抗）、`KeyInput.cs`（Alt・Ctrl・Shiftを押した時刻）、`PlayerController.cs`、`KickController.cs`、`PlayerModel.cs`（ヘディング・胸トラップの姿勢）、`MatchManager.cs`（キックの名前表示、体への当たり判定の呼び出し）
- 操作（既存キーはそのまま。修飾キーは調整ファイルで変更可）：

| 操作 | キー |
| --- | --- |
| 通常シュート | K（長押しで強く） |
| パワーシュート | Shift + K（Shift を K の直前か押している間に押したとき。ダッシュ中にそのまま K は通常シュート＝ダッシュ優先） |
| コントロール（カーブ）シュート | Alt（Option）+ K |
| グラウンダーの強いシュート | Ctrl + K |
| スルーパス | Alt（Option）+ J |
| 浮き球のスルーパス | Alt（Option）+ L |

- ショートパス：受け手の動きを読んで、到着時の球速が一定になるよう強さを計算。ロングパス：バックスピンをかけた浮き球で受け手の足元に落とす。スルーパス：味方のダッシュ速度から、走り込む先の空いたスペースへ。AIの受け手はそこへ走る。
- シュート：狙った方向がゴールラインと交わる点（ポストの内側）と高さを狙い、届く角度を逆算。コントロールシュートはインサイドの回転で曲がる分を見込んで狙う。グラウンダーはトップスピンで沈む。パワーシュートは回転が少なく速いがぶれやすい。
- 状況で自動的に変わる種類：ダイレクト（ファーストタイム）、ボレー、ハーフボレー、アウトサイド、逆足、ヘディング（高いボールにシュート/パスキー）、胸トラップ（胸の高さのボールを自動で落とす）。ボールが来る前にキーを押すと、到着に合わせて振り始める。
- カーブ量は回転速度・球速・接触の仕方（インサイド/アウトサイド）・Finishing で決まり、横向きの加速には上限あり。
- 正確さ：ShortPass / LongPass / Finishing に加えて、ダッシュ中・逆足・バランスを崩しているとき・相手が近いとき・ダイレクトやボレーのときは誤差が大きくなる。球速は ShotPower。
- 体への当たり：速いボールは足・胴・頭に当たって跳ね返る（ブロック）。ドリブル中の本人・蹴った直後の本人・キック動作中の足は対象外にして二重に当たらないようにし、同じ接触で何度も跳ね返らないよう0.15秒の間隔を設けた。

**見るところ**：キックすると画面下に `CRY #10  FINESSE SHOT` のようにキックの名前が出ます。Alt+K でボールが曲がること、ポストやネットに当たったときの跳ね方、高いボールにKでヘディングになることを確認してください。
