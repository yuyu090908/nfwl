# NFWL Unity版（Phase 1 プロトタイプ）

Unreal版 Phase 1（Sprint01）と同じ内容を Unity 6 で動くようにしたものです。
Unity版はこの `unity/` フォルダにまとめてあり、ほかのファイルには手を加えていません。

- Unityプロジェクトの場所：`unity/NFWL/`
- 対応バージョン：Unity 6（6000.6.9f1 で開く想定。6000.x ならどれでも開けます）
- はじめての方は **[Mac で開いて遊ぶまでの手順書](GUIDE_Mac_ja.md)** を読んでください。

## できること

- **5対5の試合**（フォーメーション 2-1-1、GKあり）。相手チームと味方はルールベースのAIで動きます。
- **選手キャラクター（クリスタリア族）**：yuさんのデザイン画をもとに、エルフ耳・光る瞳・トゲのある髪、肩・前腕・すねの結晶をまとった選手。結晶の色は6種類（アイス、サファイア、アメジスト、エメラルド、ゴールド、バイオレット）。ユニフォームはデザインシートどおり HOME黒・AWAY白・GK紫で、結晶柄と「NFWL」・背番号入り。走る・蹴る・GKのダイブ・ゴールで喜ぶモーション付き。
- **スタジアム**：観客席と観客、照明塔、NFWLの広告ボード、芝の質感、ゴールネット、コーナーフラッグ、模様入りのボール、夜の試合の照明。
- **画面表示**：放送風のスコアボードと試合時間（前後半10分ずつ、設計書3.1）、選手の背番号、操作中の選手のNFT選手カード（総合値・レアリティ・能力値）。

| 操作 | キー |
| --- | --- |
| 移動・ドリブル | W A S D（または矢印キー） |
| ダッシュ | Shift |
| ショートパス | J（向いている方向の味方へ。長押しで強く） |
| スルーパス | Alt（Option）+ J |
| 守備時のタックル | 相手ボールのとき、相手の近く（2.6m以内）で J |
| ロングパス | L（長押しで強く・高く） |
| 浮き球のスルーパス | Alt（Option）+ L |
| シュート | K（長押しでチャージ、強すぎると浮く） |
| パワーシュート／コントロールシュート／グラウンダー | Shift + K ／ Alt（Option）+ K ／ Ctrl + K |
| 操作する選手を切り替える | Q（ボールに一番近い味方へ） |
| カメラの寄り・引き | Z |
| キックオフに戻す／試合終了後にもう一度 | R |
| リプレイを飛ばす | Space（J / K / L でも可） |
| 音のオン／オフ | M |
| AIの役割表示（確認用） | F1 |
| 性能表示（FPS など、確認用） | F2 |
| 自動試合（CPU対CPUで見る） | F4 |

操作中の選手の足元には黄色い円が出ます。味方がボールを持つと、自動でその選手の操作に切り替わります。
試合時間は `NFWL Match` オブジェクトの Inspector にある `Half Length Seconds`（初期値600秒）で変えられます。

## 中身

v0.6（REAL FOOTBALL EVOLUTION）で増えたファイル・仕組み・確認方法・テストは [`CHANGES_v0.6.md`](CHANGES_v0.6.md) にまとめています。
v0.6 Real Football Engine の Phase 1（移動・操作感）の変更・調整値・確認手順は [`CHANGES_RFE_Phase1.md`](CHANGES_RFE_Phase1.md) にあります。

| ファイル | 役割（Unreal版の対応ファイル） |
| --- | --- |
| `Assets/Scripts/NFWLRules.cs` | ピッチ寸法・能力値換算・長押し判定・ゴール判定（NFWLTypes.h） |
| `Assets/Scripts/Pitch.cs` | 42m×25mピッチ、ライン、ゴールとネット、スタジアムを実行時に生成（NFWLPitch） |
| `Assets/Scripts/Ball.cs` | 4号球（半径11cm・0.40kg）、反発・摩擦・減衰、高速でもすり抜けない設定（NFWLBall） |
| `Assets/Scripts/PlayerController.cs` | 移動・ダッシュ・ドリブル・パス・シュート・タックル・GKのセーブ・AI（NFWLPlayerCharacter） |
| `Assets/Scripts/MatchCamera.cs` | 斜め俯瞰のサイドビューカメラ |
| `Assets/Scripts/MatchManager.cs` | 試合進行・両チームの生成・選手切替・得点・時計・画面表示（GameMode / GameState / HUD） |
| `Assets/Scripts/PlayerModel.cs` | 選手の見た目（クリスタリア族の人型モデル）とモーション |
| `Assets/Scripts/CrystalArt.cs` | 結晶の色（エレメント）、ユニフォームの色・柄・背番号、結晶の形と光る素材 |
| `Assets/Scripts/Visuals.cs` | 色・質感の共通部品と、芝・ボール・観客・広告のテクスチャをコードで生成 |
| `Assets/Scripts/KeyInput.cs` | どの入力設定でもキーボードを読めるようにする部品 |
| `Assets/Scripts/Editor/NFWLProjectSetup.cs` | 初回に `Assets/Scenes/Main.unity` を自動作成して開く |

座標は Unity の流儀（Y が上、メートル単位）。ピッチの長さ方向が X、幅方向が Z です。
